# نظام المدرسة الحديثة | MODERN SCHOOL MANAGEMENT SYSTEM (MSMS)

مشروع عربي بواجهة RTL لإدارة العمليات المدرسية، بإعداد وتطوير **Helmy Alredfani**.

## الحالة الحالية
الإصدار التمهيدي 0.1.0 هو نموذج واجهة يعمل في المتصفح، ويشمل:
- لوحة تحكم وإحصاءات أولية.
- إضافة وعرض سجلات المدارس والطلاب والمعلمين.
- بحث في سجلات الطلاب.
- تصدير نسخة احتياطية بصيغة JSON.
- دعم مبدئي لتثبيت PWA والعمل دون اتصال للملفات الأساسية.

## تشغيل المشروع
يمكن فتح `index.html` مباشرة للتجربة. لتفعيل Service Worker وPWA انشر الملفات عبر HTTPS، مثلاً GitHub Pages.

## حدود النسخة
هذه ليست منظومة إنتاجية بعد. البيانات تحفظ في `localStorage` على المتصفح والجهاز الحالي فقط. لا توجد قاعدة بيانات مركزية، أو مزامنة بين الأجهزة، أو تسجيل دخول، أو أدوار وصلاحيات، أو حماية بيانات طلاب حقيقية. وحدات الصفوف والحضور والدرجات والجدول والتقارير قيد التطوير.

## خارطة الطريق
1. تصميم قاعدة بيانات مركزية وواجهات API آمنة.
2. تسجيل الدخول والأدوار والصلاحيات وسجل التدقيق.
3. إدارة الصفوف والشعب والحضور والدرجات والجداول.
4. التقارير والطباعة والاستيراد والتصدير.
5. اختبار أمني ووظيفي قبل استخدام بيانات فعلية.
6. إعداد PWA متكاملة وتطبيق Android بعد استقرار الخادم.

## الأمان
لا ترفع بيانات طلاب أو كلمات مرور أو مفاتيح سرية إلى هذا المستودع. لا تستخدم النسخة الحالية لإدارة بيانات شخصية حقيقية.

## الترخيص
لم يُعتمد نص ترخيص نهائي في هذه النسخة. يجب إضافة ملف ترخيص كامل ومراجعته قبل إعلان إصدار عام مرخّص.
