# نظام المدرسة الحديثة | MODERN SCHOOL MANAGEMENT SYSTEM (MSMS)

مشروع عربي بواجهة RTL لإدارة العمليات المدرسية، بإعداد وتطوير **Helmy Alredfani**.

## إصدار GitHub المحلي 2.5

تعمل هذه النسخة على GitHub Pages دون خادم PHP أو قاعدة بيانات خارجية، وتشمل:

- لوحة تحكم وإحصاءات للمدرسة النشطة.
- إنشاء عدة مدارس والتبديل بينها داخل المتصفح.
- إدارة الطلاب والمعلمين والصفوف والشعب.
- تسجيل الحضور والغياب والتأخر والغياب بعذر بحسب التاريخ.
- إدارة الامتحانات بحسب العام والفصل وحد النجاح.\n- تسجيل درجات الطلاب وربطها بالامتحان والمادة، مع منع تكرار الدرجة لنفس الطالب والامتحان والمادة.\n- متابعة الرسوم المستحقة والمدفوعة والمتأخرة مع منع المبالغ السالبة أو تجاوز المدفوع للمستحق.
- إعداد جدول الحصص الدراسية.
- تقارير مختصرة قابلة للطباعة.
- تصدير واستيراد نسخة احتياطية بصيغة JSON.
- واجهة عربية RTL متجاوبة ودعم PWA والتخزين المحلي.

## رابط التشغيل

بعد نشر الفرع المعتمد عبر GitHub Pages يمكن فتح الموقع من رابط GitHub Pages الخاص بالمستودع.

## حدود التشغيل – اقرأ قبل الاستخدام

هذه نسخة **محلية على مستوى المتصفح والجهاز** وليست نظاماً مركزياً متعدد المستخدمين:
- تُحفظ البيانات في `localStorage` على المتصفح الحالي فقط.
- لا توجد مزامنة بين الأجهزة أو مشاركة مباشرة للبيانات بين المدارس.
- لا يوجد تسجيل دخول أو نظام صلاحيات أو سجل تدقيق موثوق.\n- وحدة الرسوم لا تنفذ تحصيلًا إلكترونيًا ولا تتعامل مع بيانات البطاقات.
- يستطيع مستخدم الجهاز الذي يملك وصولاً للمتصفح الاطلاع على البيانات وتعديلها.
- قد تُفقد البيانات عند مسح بيانات المتصفح أو تغيير الجهاز؛ احتفظ بنسخ احتياطية.
- لا تدخل بيانات طلاب حقيقية أو معلومات حساسة في هذه النسخة.

## تشغيل وتطوير المشروع

1. افتح المستودع على GitHub.
2. استخدم فرع التطوير `msms-1.0-foundation` لمراجعة التغييرات.
3. انشر النسخة الثابتة عبر GitHub Pages بعد الاختبار والموافقة.
4. يمكن فتح `index.html` مباشرة للتجربة، بينما يتطلب دعم PWA النشر عبر HTTPS.

## بنية التأسيس للمستقبل

يحتوي الفرع أيضاً على تصور تأسيسي لخيار خادم PHP/MySQL مستقبلي:
- `backend/database/schema.sql`
- `backend/src/Database.php`
- `backend/public/api/health.php`
- `backend/README.md`
- `docs/architecture-msms-1.0.md`

هذه الملفات ليست خادماً يعمل على GitHub Pages، ولم يتم اعتماد قاعدة البيانات لاستخدام إنتاجي.

## الأمان والنسخ الاحتياطي

لا ترفع بيانات الطلاب أو ملفات النسخ الاحتياطية أو كلمات المرور أو مفاتيح API إلى مستودع GitHub العام. استخدم بيانات تجريبية فقط.

## الترخيص

لم يُعتمد نص ترخيص نهائي لهذه النسخة.


## شؤون الطلاب وأولياء الأمور – MSMS 1.1
- سجل مستقل لأولياء الأمور داخل كل مدرسة، مع الاسم وصلة القرابة والهاتف والبريد الإلكتروني.
- ربط الطالب بولي أمر من قائمة أولياء الأمور الخاصة بالمدرسة النشطة.
- عرض ولي الأمر المرتبط في سجل الطلاب وعدد الطلاب المرتبطين في سجل ولي الأمر.
- حذف ولي الأمر لا يحذف الطلاب؛ بل يزيل الربط فقط.
- النسخ الاحتياطية القديمة تُهيّأ تلقائياً بقائمة أولياء أمور فارغة.


## التقارير المدرسية – MSMS 1.2
- مؤشرات الحضور: حاضر، غائب، متأخر، وغياب بعذر ضمن فترة زمنية قابلة للتحديد.
- كشف تفصيلي للحضور بحسب الطالب.
- ملخص نتائج الامتحانات بحسب الطالب والامتحان مع النسبة وحالة النجاح.
- كشف الرسوم المستحقة والمدفوعة والمتبقية لكل طالب، وإجمالي الرصيد المتبقي.
- طباعة التقارير من المتصفح.


## إدارة الصفوف والجدول – MSMS 1.3
- ربط الطالب بصف وشعبة من سجلات المدرسة النشطة، مع إبقاء حقل الصف النصي القديم للتوافق مع السجلات السابقة.
- اختيار الصف والشعبة المسجلين عند إنشاء الحصة بدلاً من إدخال اسم الصف كنص حر.
- ربط كل حصة بمعلم وصف من المدرسة نفسها.
- منع تكرار الصف والشعبة للعام الدراسي نفسه.
- منع تعارض حصة الصف أو المعلم في اليوم ورقم الحصة نفسيهما.
- التحقق من مراجع الصفوف في النسخ الاحتياطية، وإزالة الروابط عند حذف الصف دون حذف الطلاب أو الحصص.


## الحضور حسب الصف – MSMS 1.4
- تصفية كشف الحضور اليومي حسب الصف والشعبة، أو عرض جميع طلاب المدرسة.
- إظهار عدد الطلاب في الكشف قبل الحفظ.
- عرض اسم الصف والشعبة المرتبطين بالطالب بدلاً من الاعتماد على النص الحر فقط.
- تقرير حضور مجمع لكل صف: عدد الطلاب، الحاضر، الغائب، المتأخر، بعذر، ونسبة الحضور ضمن الفترة المحددة.
- حفظ الحضور يقتصر على الطلاب الظاهرين في الكشف الحالي؛ لا تتأثر سجلات الصفوف الأخرى عند استخدام التصفية.


## الجدول الأسبوعي المرئي – MSMS 1.5
- عرض بصري أسبوعي للحصص من الأحد إلى السبت، مرتبة حسب رقم الحصة.
- إظهار المادة والصف والشعبة والمعلم في خانة اليوم والحصة.
- تصفية الجدول حسب الصف والشعبة أو عرض جدول المدرسة بالكامل.
- الإبقاء على سجل الحصص التفصيلي لإضافة الحصص وتعديلها وحذفها.


## شؤون الموظفين والمعلمين – MSMS 1.6
- ملفات وظيفية مستقلة للموظفين: المسمى الوظيفي، القسم، الهاتف، البريد، تاريخ التعيين، والحالة الوظيفية.
- سجل طلبات الإجازة والاستئذان: الموظف، النوع، تاريخ البداية والنهاية، الحالة والملاحظات.
- حساب مدة الطلب بالأيام، مع تصفية الطلبات حسب الحالة.
- التحقق من ارتباط الطلب بموظف في المدرسة النشطة، ومن صحة الفترة الزمنية.
- منع تداخل فترات الإجازات الموافق عليها للموظف نفسه.
- تقرير العبء التدريسي للمعلمين اعتماداً على عدد الحصص في الجدول الأسبوعي والصفوف المكلفين بها.
- حذف الموظف يزيل طلبات إجازته المرتبطة به.
- تهيئة مجموعتي الموظفين والإجازات تلقائياً عند فتح بيانات المتصفح القديمة، والنسخ الاحتياطية القديمة.


## دوام الموظفين – MSMS 1.7
- سجل يومي لحضور الموظفين وغيابهم وتأخرهم والإجازة والاستئذان.
- تحديد تاريخ السجل وتصفية النتائج حسب الموظف.
- تسجيل وقت الحضور والانصراف والملاحظات.
- ملخص يومي بعدد الحاضرين والغائبين والمتأخرين والموجودين في إجازة أو استئذان.
- منع تكرار سجل الموظف في اليوم نفسه والتحقق من ترتيب وقت الحضور والانصراف.
- التحقق من روابط الموظفين في النسخ الاحتياطية، وإزالة سجلات الدوام عند حذف ملف الموظف.
- تهيئة مجموعة دوام الموظفين تلقائياً للبيانات والنسخ الاحتياطية القديمة.


## التقارير الإدارية الشهرية – MSMS 1.8
- اختيار الشهر وعرض بيانات المدرسة النشطة فقط.
- مؤشرات عدد الموظفين وسجلات الدوام والحضور والغياب والتأخر وأيام الإجازة المعتمدة.
- تفصيل شهري لكل موظف بحسب القسم وحالات الدوام والإجازات والاستئذان.
- تقرير العبء التدريسي للمعلمين بحسب الحصص الأسبوعية والصفوف والشعب.
- تصدير التقرير إلى CSV بترميز UTF-8 المتوافق مع برامج الجداول الإلكترونية.
- احتساب أيام الإجازة المعتمدة المتداخلة مع الشهر مع الاقتصار على الأيام الواقعة داخله.


## التحليلات المالية الشهرية – MSMS 1.9
- تقرير الرسوم بحسب شهر الاستحقاق للمدرسة النشطة.
- مؤشرات إجمالي المستحق والمدفوع المسجل والمتبقي ونسبة التحصيل.
- حساب رصيد الرسوم المتأخرة حالياً وعدد بنودها على مستوى المدرسة.
- تفصيل الرسوم حسب الطالب والصف والشعبة.
- تصدير تفاصيل الطلاب والصفوف إلى CSV بترميز UTF-8.
- يراعي التقرير أن حقل المدفوع الحالي قيمة تراكمية مسجلة في بند الرسوم، وليس سجل قبض بتاريخ مستقل؛ لذلك لا يدعي أنه تقرير حركة نقدية يومية أو شهرية.
- البنود التي لا تحتوي على تاريخ استحقاق لا تدخل في تحليل شهر محدد.


## سندات القبض وسجل المدفوعات – MSMS 2.0
- إنشاء سند قبض مرتبط ببند رسوم محدد، مع المبلغ وتاريخ القبض وطريقة الدفع ورقم المرجع والملاحظات.
- تحديث المبلغ المدفوع والمتبقي في بند الرسوم تلقائياً عند تسجيل السند أو تعديله أو حذفه.
- منع تجاوز الرصيد المتبقي، ومنع تغيير الطالب أو خفض المدفوع عن مجموع السندات المرتبطة ببند الرسوم.
- عرض سجل سندات القبض للمدرسة النشطة، وربط كل سند بالطالب وبند الرسوم.
- إدراج سندات القبض المؤرخة في التقرير المالي الشهري بحسب تاريخ القبض، مع المجموع وعدد السندات وتفاصيل كل سند.
- تضمين سجل السندات في النسخ الاحتياطية والتحقق من الروابط والمبالغ والتواريخ ومجموع السندات عند الاستيراد.
- تهيئة مجموعة السندات تلقائياً عند فتح بيانات أو نسخ احتياطية أقدم لا تحتوي عليها.
- هذا سجل محاسبي محلي وليس بوابة دفع؛ لا يوجد اتصال مصرفي أو تحقق آلي من التحويلات.


## سندات القبض وسجل المدفوعات – MSMS 2.0
- إنشاء سند قبض مرتبط ببند رسوم محدد، مع المبلغ وتاريخ القبض وطريقة الدفع ورقم المرجع والملاحظات.
- تحديث المبلغ المدفوع والمتبقي في بند الرسوم تلقائياً عند تسجيل السند أو تعديله أو حذفه.
- منع تجاوز الرصيد المتبقي، ومنع خفض المدفوع عن مجموع السندات أو تغيير الطالب في بند رسوم بعد تسجيل قبض.
- عرض سجل سندات القبض للمدرسة النشطة وربط كل سند بالطالب وبند الرسوم.
- إدراج سندات القبض المؤرخة في التقرير المالي الشهري بحسب تاريخ القبض، مع المجموع وعدد السندات وتفاصيل كل سند.
- تضمين السندات في النسخ الاحتياطية والتحقق من المراجع والمبالغ والتواريخ ومجموع السندات عند الاستيراد.
- تهيئة مجموعة السندات تلقائياً عند فتح بيانات أو نسخ احتياطية أقدم لا تحتوي عليها.
- هذه وحدة تسجيل محاسبي محلية وليست بوابة دفع؛ لا يوجد اتصال مصرفي أو تحقق آلي من التحويلات.


## طباعة سندات القبض – MSMS 2.1
- إنشاء رقم سند تلقائي فريد لكل عملية قبض، مع الحفاظ على الرقم عند تعديل السند.
- عرض رقم السند في سجل القبض والتقرير المالي الشهري وملف CSV.
- طباعة سند مستقل يتضمن المدرسة والطالب وبند الرسوم والمبلغ والتاريخ وطريقة الدفع والمرجع والملاحظات.
- ترقية سندات القبض القديمة تلقائياً بإسناد رقم عند فتح البيانات أو استيراد نسخة احتياطية.
- التحقق من وجود رقم السند ومنع تكراره داخل المدرسة عند استيراد النسخ الاحتياطية.


## كشف حساب الطالب – MSMS 2.2
- كشف مستقل للطالب المختار في المدرسة النشطة، مع بياناته ورقم قيده وصفه وشعبته.
- عرض بنود الرسوم وتواريخ الاستحقاق والمبالغ والمدفوع المسجل والمتبقي وحالة السداد.
- عرض سندات القبض المرتبطة ببنود رسوم الطالب، متضمنة رقم السند والتاريخ والمبلغ وطريقة الدفع والمرجع.
- ملخص إجمالي المستحق والمدفوع المسجل والمتبقي والمتأخر، وإجمالي سندات القبض ضمن الفترة.
- تطبيق نطاق التاريخ على تاريخ استحقاق الرسوم وتاريخ القبض كلٌ على حدة، دون الخلط بينهما.
- طباعة كشف مستقل وتصديره إلى CSV بترميز UTF-8.
- التقرير للقراءة فقط ولا يعدّل أرصدة الرسوم أو سندات القبض، ويقتصر على المدرسة النشطة.


## بطاقة نتيجة الطالب – MSMS 2.3
- اختيار طالب وامتحان من المدرسة النشطة لإعداد بطاقة نتيجة فردية.
- عرض الدرجات التفصيلية لكل مادة مع الدرجة النهائية والنسبة وحالة المادة.
- احتساب المجموع والنسبة الإجمالية ومقارنتها بحد النجاح المحدد في بيانات الامتحان.
- إظهار بيانات الطالب والصف والامتحان والعام الدراسي والفصل والتاريخ.
- طباعة بطاقة مستقلة وتصديرها إلى CSV بترميز UTF-8.
- البطاقة للقراءة فقط، وتعرض الدرجات المرتبطة بالطالب والامتحان داخل المدرسة النشطة دون تعديل السجلات.


## تحديثات GitHub Pages والتخزين المؤقت – MSMS 2.4
- يستخدم Service Worker رقم cache جديداً لإبطال ملفات الموقع القديمة المخزنة في المتصفح.
- تحميل صفحات الموقع أصبح Network-first، بحيث يجلب أحدث نسخة منشورة عند توفر الإنترنت ويحدّث النسخة المحلية، مع الرجوع إلى نسخة cache عند انقطاع الاتصال.
- تُحذف نسخ cache السابقة عند تفعيل Service Worker الجديد.


## التحليلات الأكاديمية – MSMS 2.5
- مؤشرات الطلاب الذين لديهم نتائج، والنتائج الناجحة والراسبة، ومتوسط النسبة ضمن الفترة المحددة.
- تحليل الأداء حسب المادة: عدد النتائج، متوسط النسبة، وعدد الناجحين والراسبين ونسبة النجاح.
- تحليل الأداء حسب الصف والشعبة والامتحان، مع عدد الطلاب ومتوسط النسبة ومؤشرات النجاح والرسوب.
- يعتمد التحليل على درجات الامتحانات المسجلة والطلاب والامتحانات في المدرسة النشطة فقط.
- يطبق نطاق التاريخ على تاريخ الامتحان، ويتيح تصدير ملخص التحليل إلى CSV.
- التقارير للقراءة فقط ولا تعدّل درجات الطلاب أو سجلات الامتحانات.
- تم تحديث رقم الإصدار الظاهر في الواجهة إلى MSMS 2.5.
